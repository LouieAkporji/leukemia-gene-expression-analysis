# Leukemia Gene Expression Analysis

A collection of R-based statistical analyses exploring gene expression patterns in leukemia datasets. The analyses use gene expression data from acute lymphoblastic leukemia (ALL) and acute myeloid leukemia (AML) samples to demonstrate statistical methods commonly used in bioinformatics.

## Project Overview

This project explores leukemia gene expression data using several statistical approaches, including:

- Comparing gene expression between ALL and AML samples
- Performing t-tests and nonparametric statistical tests
- Applying Bonferroni and False Discovery Rate (FDR) corrections
- Conducting ANOVA and pairwise comparisons
- Examining relationships between gene expression measurements
- Using correlation analysis and regression
- Applying bootstrap methods to estimate uncertainty

## Scripts

- `l_akporjiHW7.R` — ALL/AML gene expression comparisons and multiple testing correction
- `l_akporjiHW8.R` — Gene-specific expression analysis and nonparametric statistical testing
- `l_akporjiHW9.R` — Gene expression across leukemia cell stages using ANOVA and related statistical tests
- `l_akporjiHW10.R` — Gene expression correlation analysis alongside bootstrapping and regression methods

## Background

These analyses were developed through statistical computing coursework and use biological datasets to apply statistical methods relevant to bioinformatics and gene expression research.

The repository demonstrates experience using R to explore biological data, perform statistical analyses, and interpret gene expression patterns.
